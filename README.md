This project focuses on security, privacy, and responsible use of Generative AI in the aviation industry. The main objective of the activity is to understand how personal, sensitive, travel, medical, financial, and confidential information can create privacy and security risks when entered into AI tools. The project demonstrates practical methods for protecting information while still using Generative AI for professional aviation tasks.

The activity begins by identifying different types of privacy risks. Information such as passenger names, passport numbers, Aadhaar numbers, mobile numbers, personal email addresses, booking references, medical information, payment-card details, and travel information is reviewed according to its sensitivity. Highly sensitive information, including government identification, medical information, and financial details, is identified for removal, while other information is replaced with appropriate placeholders. Unsupported commitments related to baggage delivery and compensation are also identified as risks because AI may generate information that has not been verified.

A major part of the project focuses on replacing real information with privacy-safe placeholders such as [PASSENGER NAME], [BOOKING REFERENCE], [FLIGHT NUMBER], [TRAVEL DATE], and [VERIFY AIRLINE POLICY]. This approach allows the structure and purpose of an AI prompt to remain intact without exposing actual personal or confidential information. The project also demonstrates how to create a privacy-safe baggage-delay communication using only necessary information and authorised verification channels.

The activity further compares unsafe and safe prompts and classifies information according to sensitivity levels, including Public, Internal, Confidential, and Restricted/Highly Sensitive. Several aviation scenarios are examined, including flight cancellation, special assistance, employee security reports, and payment complaints. Each scenario is redesigned using placeholders, data minimisation, and appropriate verification instructions.

A security-audit checklist is also used to determine whether prompts contain personal information, payment details, medical information, employee credentials, confidential operational information, or unnecessary data. The project highlights the principle of data minimisation, which means sharing only the information necessary to complete a task.

Overall, this project demonstrates the importance of privacy-aware Generative AI practices in aviation management. It shows that sensitive information should be protected, unnecessary data should be removed, authorised systems should be used for verification, and AI-generated content should receive appropriate human review before professional use.
